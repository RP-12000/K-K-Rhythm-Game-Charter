# K & K Charter（谱面编辑器）

K&K 节奏游戏的谱面编辑器。直接打开、保存游戏自己的谱面文件，格式和游戏完全一样（v4，包括变速 `bpmList`）；旧的 v1、v2、v3 谱面打开时自动换算到现在的坐标（判定线 1080 / 120），保存后变成 v4。

## 运行

- 游戏文件夹要放在旁边：默认是 `../K and K Rhythm Game`，换位置就改 `gradle.properties` 里的 `gameDir`。
- IntelliJ：打开本文件夹 → 刷新 Gradle → 运行 `lwjgl3 › Tasks › application › run`。命令行：`gradlew lwjgl3:run`。
- 编辑器直接编译游戏的代码（谱面读写、判定线、音符画面），所以预览看到的就是游戏里的样子，保存的文件游戏一定能读。所以编辑器和游戏要一起更新：旧的编辑器读不了新格式的谱面。
- 谱面文件是游戏的 v5 格式（2026-10-27 起，Kelvin：「把整个谱面文件全部重构」「包括制谱器那边的」，见游戏 `docs/CHART_FORMAT.md`）：默认值不写，难度文件里只有这个难度自己的东西，歌名、曲师、画师、BPM、变速、offset 保存时写进同一个文件夹的 `song.json`（其他键原样保留）；编辑器自己的数据（迭代次数、统一流速、流速 BPM）在顶层 `"editor"` 里，事件上的 `rel`、`flow` 照旧。旧格式（v1–v4）照样能打开，保存后写成 v5。保存时用游戏的转换器把 v5 读回来逐项比对，有不一样的地方就先存成 v4（游戏照样能读）。没保存的修改和撤销仍用 v4 文字。
- 给没有游戏的人用：在本文件夹运行 `gradlew lwjgl3:packageWinX64`（第一次要下载 Java，约 190 MB），得到 `lwjgl3/build/construo/dist/K & K Rhythm Game Charter-winX64.zip`（约 53 MB，带 Java）。解压后双击 exe 就能用，不用装 Java，也不用游戏；Mac、Linux 用 `packageMacM1` / `packageMacX64` / `packageLinuxX64`。只要 jar 的话是 `gradlew lwjgl3:jar`（`lwjgl3/build/libs/`，要装 Java 11 以上）。打包时要有游戏的代码，用的时候不用。
- 旁边没有游戏时，谱面存在程序旁边的 `Charts/`（每首歌一个文件夹：谱面 json、音频、曲绘、song.json），`backups/`、`trash/` 也在程序旁边。把那首歌的整个文件夹压缩成 zip 发给 Kelvin，解压进游戏的 `assets/Charts` 就行。
- 预览是 16:10 的一屏，就是游戏的 1920 × 1200 参考画面（2026-10-19 起，Kelvin：「坐标系我们现在修改为1920*1200」）：纵向的数字都按 1200 高算，默认判定线 1080 / 120（各离屏幕边 120，Kelvin 10-19 定），默认下落 2 拍内 1080 → 0（Kelvin 10-19：「默认下落改为两拍1080的距离」），尾长建议值每拍 540，判定区线上下各 480，所以两条线的判定区正好在屏幕中间接上。这些默认值直接取游戏的常量。v3 谱面打开时只换判定线：线的位置和线的事件以屏幕中线为中心乘 36/35（1066.67 / 133.33 → 1080 / 120），下落、尾长、旋转中心都不变；v1、v2 的纵向数字先乘 1200/1080 再换线。游戏在 16:9 屏幕上把纵向压到 0.9 倍。预览里的选中框、拖动手柄和旋转中心十字跟着游戏画音符的位置（离线远的轨道音符比距离再远一点：水滴、水流 2.22，水雷 1.78，到线时回到 0）。

## 安卓平板版

- 排版按 16:10 平板做（1344 × 840 的画面，右边属性面板和电脑版一样宽），全屏横屏，要 Android 8.0 以上。电脑上加 `-Dkk.tablet=true` 运行可以看平板排版。
- 打包：用 Android Studio 打开本文件夹，等 Gradle 同步完，`Build › Build APK(s)`（或者连上平板直接点运行），APK 在 `android/build/outputs/apk/debug/`。要有 `local.properties`（一行 `sdk.dir=` Android SDK 的位置，可以从游戏文件夹复制）；没有它的时候只编译电脑版，所以打 exe 不用装 Android 的东西。
- 打包时把游戏的 `assets/Charts` 和 `assets/Introduction` 一起放进 APK。平板上第一次打开时复制到应用自己的文件夹 `Android/data/org.kelvinizer.charter/files/`（`Charts/`、`Introduction/`、`backups/`、`trash/` 都在这里）。每首歌只复制一次（记在 `seeded.txt`），平板上改过的不会被新装的 APK 盖掉。
- 把平板上改好的谱面拿回电脑：数据线连电脑，在「内部存储 › Android › data › org.kelvinizer.charter › files › Charts」里复制那首歌的文件夹，放进游戏的 `assets/Charts`。曲库的「打开文件夹」会显示这个位置。
- 操作：一次只认一根手指；点输入框弹出系统键盘；快捷键换成预览下面一排按钮（撤销、重做、复制、粘贴、删除、全选、多选、◀ ▶ 按吸附走一格、统计），「多选」开着时点音符是加选；时间轴左下角 − / + 缩放；返回键回曲库。切到后台时把没保存的修改存一份到 `backups/autosave/`。
- 选音频和曲绘用系统的文件选择器（先复制一份再导入）；变速播放用 Android 的 MediaPlayer，和电脑版一样变速也变调。

## 文件在哪

| 内容 | 位置 |
|---|---|
| 谱面 | 游戏的 `assets/Charts/<歌名>/Surface.json` / `Shallow.json` / `Deep.json` / `Abyss.json`（旁边没有游戏时是程序旁边的 `Charts/<歌名>/`） |
| 歌曲信息、曲绘、音频 | 同一个文件夹：歌名、曲师、画师、BPM、变速、offset 在 `song.json`，还有 `jacket.png`、`.mp3` / `.wav` / `.ogg` |
| 曲绘取景、歌曲试听段 | 同一个文件夹的 `song.json`（`jacket16x9`、`jacketCircle`、`previewStartMs`、`previewEndMs`、`previewStartBeat`、`previewEndBeat`，其他键原样保留） |
| 保存前的旧文件 | 本文件夹 `backups/<歌名>/`（每次保存都备份一份） |
| 没保存的修改 | `backups/autosave/`（每 2 分钟） |
| 删掉的歌 | `trash/`（只是挪过去，没有真的删除） |
| 换一个谱面文件夹 | 在本文件夹建 `charter.properties`，写一行 `charts=路径` |

## 操作

| 按键 | 作用 |
|---|---|
| 空格 / Home | 播放、暂停 / 回到开头 |
| 1 2 3 4 5 6 7 8 | 工具：水滴、水流、水雷、轨道水雷、浪花、潮汐、浪花水雷、潮汐水雷 |
| 9 0 | 工具：漩涡、水帘（在预览空白处点一下，以那里为中心放一块圆形的，从播放头开始 8 拍） |
| N | 选择和上次用的工具来回切换（一开始是水滴） |
| 点击 | 放音符；长的几种（水流、轨道水雷、潮汐、潮汐水雷）按住往远处拖出长度，只点一下是 1 拍 |
| Tab | 新音符放上线还是下线 |
| 右键 | 删除鼠标下的音符 |
| 滚轮 / Ctrl+滚轮 | 走时间 / 缩放时间轴 |
| 拖底部「音频」那一行 | 左右拖着走时间（单击 = 跳到那里） |
| D | 选中的音符套用「正常下落」（判定前 2 拍从屏幕外落到线上，相对判定） |
| ← → / ↑ ↓ | 按吸附走一格 / 选中的音符前后挪一格 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| Ctrl+C X V A | 复制、剪切、粘贴（到播放头）、全选 |
| Del、M、Shift+M、Esc | 删除、左右镜像、上下镜像（天键 ↔ 地键）、取消选择 |
| Ctrl+S | 保存（保存前会自动检查谱面） |

时间轴上可以拖动框选、拖音符改时间；右边面板「谱面」改曲名、定数、变速和偏移（曲名、曲师、画师和变速四个难度共用：保存时会一起写进这首歌的其他难度，改之前先备份；新建的空白难度也带上这首歌的变速），「音符」改单个音符和它的运动，「场地」改轨道、全局缩放、镜头平移和判定线位置，「漩涡」加和改漩涡，「水帘」加和改水帘。

- 右边的编辑栏：滚轮、拖最右边的滚动条（点滚动条空的地方直接跳过去）、按住空白处上下拖，都能滚动。
- 「谱面」页「流速」：「统一拍数」= 按拍下落（2 拍内 1080 → 0，BPM 越高越快）；「统一流速」= 正常下落、快捷运动和新放的音符按「流速 BPM」的拍数算时间，比如 BPM 240、流速 BPM 120 时是 4 拍内 1080 → 0，看起来和 120 BPM 一样快。流速 BPM 可以从某一拍起分段改。切换时整首谱里「一段相对下落、落到判定线」的音符一起换（可以撤销）；之后改 BPM、改流速或挪音符都会自动重新对齐，尾长还是建议值的长条尾巴也跟着变；手动改过开始/结束拍的下落就不再跟流速。文件里写的仍是普通的拍，游戏不用改；`fallBy`、`flowBpmList` 和移动事件上的 `"flow"` 只给编辑器自己用。
- 「音符」页：轨道可以直接填编号，或点 ‹ › 往左右挪一条。每段事件（移动、长度、透明度、旋转）添加时选「+ 相对判定」（填距判定几拍，负数在判定前，改判定拍时跟着走）或「+ 绝对拍」（填第几拍，改判定拍时不动），之后点那一段的「相对 / 绝对」可以改。复制粘贴音符时也一样：相对的跟着走，绝对的留在原来的拍子；只有「整体平移」会把绝对事件也一起移。「全部相对 / 全部绝对」一次改选中音符的全部事件。旧谱面里自动填的默认下落（判定前 2 拍 1080 → 0，v1、v2 文件里写的是 972 → 0）算相对判定，其余事件都是绝对拍；全局事件（缩放、镜头平移、判定线）一律绝对拍。「正常下落」按钮和「更多快捷运动」一键套用常用运动（相对判定）。相对的事件在文件里照样写绝对拍，另加编辑器专用的 `"rel": true`（改成绝对的默认下落写 `"rel": false`），游戏不读它。
- 曲库最后一行（「练习谱」里）是「新手教程 · …」：游戏的新手教程（Charts 旁边的 `assets/Introduction`，由 Charts/index.json 的 `"tutorial"` 指定），带它的音乐，直接改原来的文件，备份在 `backups/Introduction`。它不能在编辑器里删除，也别把它搬进 Charts（游戏会把它当成一首单曲）。
- 「谱面」页「本难度」里的「迭代次数」：这张谱经过了多少版，存在文件的 `"iterations"` 里，游戏不读。编辑器保存前会备份旧文件，每备份一次 +1，也就是打开编辑器后第一次保存这张谱的时候；保存时一起改到的其他难度（共用的曲名、BPM）也各 +1。写谱辅助改谱时也会 +1，编辑器不会把文件里更大的数改小。
- 「音符」页「旋转」下面的「旋转中心」：「自转」固定绕键自己的中心转（长条是底部那块的中心）；旧谱里写过别的自转中心（`"pivot": [x, y]`）的照旧保留，可以点「改回键中心」。「公转」见下面。
- 「音符」页最下面的「拖拽残影」和「故障」都可以分几段：每段有自己的范围（从第几拍到第几拍，空着 = 不限）和参数，段和段之间没有效果；「+ 加一段」接在上一段后面，「删除」去掉一段。故障的强度 0–1（填了「结束」就渐变过去，指数是缓动）、速度（每拍换几次花样）、色散 / 错位 / 闪断比重 0–2，只影响画面、不影响判定，预览里直接看得到。拖动音符时两者的范围跟着走。残影数 = 长度 × 密度，每段最多 256 个（2026-10-22 起）；同屏残影太多时，游戏会让所有残影一起均匀变稀。
- 「音符」页最下面的「扭曲」（游戏 CHART_FORMAT §6.11，Kelvin 2026-10-23）：和故障一样分段写，每段有范围（空着 = 不限）和强度（开始 / 结束，0–4，填了「结束」就渐变过去，指数是缓动）。键平常是 0（不扭曲），1 = 和漩涡平常一样，2 = 两倍；两段重叠时后开始的那段起作用。只影响画面，预览里直接看得到，拖动音符时范围跟着走。文件里写成音符的 `"distortion"`。
- 「漩涡」页（游戏 CHART_FORMAT §6.10，Kelvin 2026-10-23）：挡住判定的漩涡，圆形（同心圆）或多边形（光网，3–16 个点），放在画面任何地方，不属于轨道。在漩涡里按下的手指抬起前什么都判定不了（不断连击）；音符的时间不变，透明度 0 时不挡。「+ 圆形漩涡」「+ 多边形漩涡」从播放头开始加一块（8 拍）。点列表里的一块选中它，可以改形状、半径或各个点（从中心量，y 向上）、中心、角度、透明度、出现的拍（空着 = 不限），加横移、竖移、旋转、透明度事件，以及故障和扭曲（漩涡平常是 1，0 = 不扭曲，最多 4）。在「漩涡」页用选择工具时，预览里画出每块漩涡真正挡住的轮廓：拖漩涡移动它（横移、竖移事件一起移），拖顶点改形状，拖圆形右边的点改半径，Del 删掉选中的漩涡。检查里会提示点不够 3 个的多边形（游戏会丢掉它）和判定时整个判定区都被漩涡盖住的音符。文件里写成谱面最后的 `"veils"`。
- 「音符」页「波动速度」（浪花、潮汐和它们的水雷，Kelvin 2026-10-28）：每拍移动几个波，0 = 不动，负数往左；地上是波往旁边流，天上是珍珠串往旁边移。只影响画面，文件里写 `"waveSpeed"`。
- 「音符」页「横移」（轨道上的音符，Kelvin 2026-10-28）：键身离轨道中心往右挪多少，下面的「横移 OffsetX」事件让它随时间左右滑（有事件时，事件外回到轨道中心）。判定和打击效果还在原来的轨道。文件里写 `"offsetX"` 和 `"offsetXEvents"`。
- 「音符」页「公转」（轨道上的音符，Kelvin 2026-10-29）：绕画面上的一点转（中心 x、y 按 1920 × 1200 量，可以加中心的移动事件），还可以填「半径」「角度」和它们的事件，让键按半径和角度绕中心走。半径、角度和移动事件同时写了又对不上时，检查里提示「物件坐标冲突」，在「坐标冲突时」选「以公转为准」或「以移动为准」就不再提示。
- 假键（音符页「假键」开关，游戏 7.167 / 7.169）默认不画在底下的时间轴上，也点不中；预览上方「时间轴假键」打开后才显示（Kelvin 2026-11-02）。
- 「音符」页「不跟判定线」（Kelvin 2026-11-03）：选中一个或几个键，填「从」「到」（拍，默认从最早的下落到最后一个判定），按「抵消判定线运动」，这段时间里判定线上下动（比如抖动）时这些键不跟着动，停在判定线按「从」那一拍的位置算的地方。只改这些键的运动事件（判定线动的那一段重新切开，缓动的部分每 1/64 拍切一段），游戏代码不变，可以撤销。默认下落的键先写成显式的下落事件；按公转半径或角度走的键不改。
- 轨道宽度和判定线位置在右边「场地」页改（Kelvin 2026-11-01 去掉了左边的「轨道」「判定线」工具）。
- 「浪花水雷」工具（键 7，长的是键 8「潮汐水雷」，游戏 CHART_FORMAT §5.1，Kelvin 2026-10-31）：浪花的水雷版本，画成红色的浪花，整条线、不分轨道。浪花水雷在这条线的判定区里按下就算碰到；潮汐水雷这段时间整条线的判定区都封住。同一条线上落在潮汐水雷里的音符检查里会提示。文件里写 `"tideMine"`，不写轨道。
- 「水帘」页（游戏 CHART_FORMAT §6.1，Kelvin 2026-10-31）：和漩涡一样加、选、拖、改，只是纯演出：盖住的东西（音符、判定线、连击、分数、暂停键）都变模糊，不挡手指、不判定。多一个「模糊强度」（默认 16，0–64，0 = 不模糊）和「模糊 Blur」事件。预览和「实机」里都画。文件里写成 `"curtains"`。
- 「场地」页：默认「无限轨」：轨道从中轴（−1 和 +1 轨之间）往两边排，每条宽度固定（默认 240），画面露出几条就画几条，外面的轨道也在，音符可以放到任何编号的轨道。选「有限轨」再填总数，就只有这么多条轨道，按宽度比例分满「画面宽 × 全局缩放」；改总数时要删掉的轨道上有音符，会先问你（可以撤销）。总数存在谱面的 `laneCount` 里，没有这一项 = 无限轨。
- 无限轨时「场地」页的「整理轨道」：删掉谱面里写出来、但没放音符、整首歌都不会出现在画面上的轨道（先问你，可以撤销）。有自己宽度或透明度设置的轨道，删了会让画面里的轨道移位或多出一条的，会留着并告诉你。
- 「场地」页的轨道插入（游戏 CHART_FORMAT §3.6）：「插入0号轨」在 −1 和 +1 之间插一条 0 号轨；按住 Ctrl 点选相邻的两条轨道，再点「在 X 和 Y 之间插入」插在它们中间，没有空编号时外侧轨道连同音符和事件往外顺延一个编号（比如插在 +2、+3 之间，原来的 +3、+4 变成 +4、+5，新轨道是 +3）。新轨道从播放头所在的拍开始，1 拍内从 0 长到两边轨道的平均宽度；选中它可以像事件一样改开始拍、结束拍、初始大小、最终大小和增长速度，也可以「删掉插入的轨道」（外侧轨道挪回来）。无限轨时屏幕里的轨道一起变窄给它让位。插入开始前放在这条轨道上的音符打不到，检查里会报错。
- 「场地」页的删除轨道事件（游戏 CHART_FORMAT §3.7）：选中一条轨道，点「+ 删除轨道事件（从当前拍开始）」，它从播放头所在的拍开始，1 拍内从当时的宽度缩到 0；可以改开始拍、结束拍、开始宽度、最后宽度和速度，也可以「取消删除」。从开始拍起宽度事件不再起作用，删完以后轨道没了：无限轨时两边合拢，屏幕里的轨道一起变宽（插入的轨道再删掉就回到插入以前）。轨道编号和按键不变，删完以后放在这条轨道上的音符检查里会报错。文件里写成轨道上的 `"delete"`，旧版编辑器保存时会丢掉它。
- 缩放：「全局缩放」的倍数和事件让所有轨道一起变宽变窄（以中轴为准）；「部分缩放」= 点轨道编号时按住 Ctrl 多选或 Shift 连选，填开始拍、结束拍和倍数，一键给这些轨道加宽度事件。
- 镜头平移：中轴离画面中心多远（正数往右），所有轨道跟着移；加事件就能让轨道左右平移。它代替了以前的左右边框：旧谱面的边框读进来时换成全局缩放和平移，存的时候不再写左右边框。
- 轨道水雷：「时长」= 封锁这条轨道多久；「红区长度」和它的事件 = 红区多长，落到判定线后底部不动，红区还能变长变短。检查里，按键或长条头落在封锁里算警告（黄色 ⚠，和游戏一样照常读谱）。水雷不受限制（Kelvin 2026-10-22：「地雷的限制不用那么多」）：同一条线、同一轨、同一拍可以叠好几个水雷，也可以和按键放在同一个位置，游戏都会保留，检查也不提示。
- 预览右上角「sync」按钮在「高亮 / 增强 / 关」之间切换，和游戏设置里的 SYNC HINT 一样（默认高亮），只影响预览，不写进谱面。
- 预览右上角「实机」按钮（Kelvin 2026-10-27）：打开后预览像游戏的自动播放一样画分数、连击、判定字、难度和定数、曲名、剩余时间、进度条和打击特效（水花、波纹、迷失等），只是没有暂停键、不放打击音；左上角「预览：第几拍」和选中框、拖动手柄这些编辑标记都隐藏。再点一下回到编辑的样子。拖动播放头跳过去时不补放中间的打击特效，分数和连击直接算到那一拍。
- 音频比谱面短时（比如现在用 Aleph-0 占位的歌），音乐放完后时间照样走，一直播到最后一个音符，只是没有声音。
- 状态栏右下角「统计」：点开看各类音符的数量（分上线 / 下线）、物量（计分的音符，不含水雷）、sync 音符（同一拍还有别的音符）、各类事件的数量和事件总数，以及轨道、变速段数、拖影、时长和密度。点别处或按 Esc 关掉。
- 难度在编辑器里和游戏一样显示为 Shallow / Medium / Deep / Abyss（Kelvin 2026-10-27 改名）；谱面文件名仍是 `Surface.json` / `Shallow.json` / `Deep.json` / `Abyss.json`，下面写的 Surface、Shallow 指文件。
- 曲库不列 Song 1–5（Kelvin 2026-11-01，`Library.HIDDEN`）；它们的文件夹不动，自测时照常列出。
- 曲库下面的「练习谱」（Kelvin 2026-11-02，`Library.PRACTICE`）：和上面的单曲分开，依次是主线的 Aleph-0、marsh mally（游戏 Charts 里的，不能在编辑器里删除），Charter 自己 `practice/` 文件夹里的歌（Altale，游戏里没有），最后是新手教程。
- 「导入音频」新建一首歌（Kelvin 2026-10-22）：填好文件夹名和 BPM 后直接建好 Surface、Shallow、Deep 三个空谱面（定数 1、2、3），并打开 Surface。还没有谱面的歌在曲库里点「+ 新建」也一样（点的是 Abyss 就再加一个 Abyss 并打开它）。之后单独新建的空白 Surface / Shallow / Deep 也用这三个定数，Abyss 是 1。
- 曲库里点曲绘可以换图（png / jpg），选好后先打开「曲绘取景」（Kelvin 2026-10-21：「有些曲绘不是16：9就需要我选定区域，圆形部分也要我选定」）：在整张图上拖一个 16:9 的框（选歌卡片、结算显示这一块）和一个圆（地图上的洞、进歌时的转场显示这个圆），右上的按钮或 Tab 换框，拖框移动，拖角上的点或滚轮调大小，「重置」= 居中最大，右边预览两处的样子。确定后图片原样复制成 `jacket.<扩展名>`（不裁），旧的 `jacket.*` 移到 `trash/`；两个框按图片宽、高的比例写进 song.json：`"jacket16x9"` 和 `"jacketCircle"`（圆外接的正方形），都是 `{"x", "y", "w", "h"}`，`y` 从上往下量。框是居中最大的就不写（游戏没有框时就居中裁）。歌曲详情里的「曲绘取景」按钮随时改现在这张曲绘的两个框。曲库列表和详情里的方形曲绘显示圆外接的正方形。
- 「谱面」页画师下面的「预览起点」「预览终点」（新手教程没有）：游戏歌曲列表试听的起点和终点（Kelvin 2026-10-21：「参数改为起点和终点而不是起点和持续时长」，之后又改成按拍），以拍填，或用「起点设为播放头」「终点设为播放头」，也可以直接在时间轴音频那一行拖青色「预览」框的两条边（按吸附取整，按住 Shift 不吸附）；「▶ 试听预览」从起点放到终点停。起点可以在音乐开始之前（先静音），终点可以超过音乐结尾。写进 song.json 的 `previewStartBeat` / `previewEndBeat`（拍）和游戏读的 `previewStartMs` / `previewEndMs`（毫秒，按这张谱的 BPM 和偏移换算）；以后改了 BPM 或偏移，保存谱面时毫秒跟着拍重算。没写时游戏从整首歌 30% 处开始放 20 秒，「恢复默认」删掉这四个键。曲库里的试听也按这一段放。
- 谱面文件在编辑器外被改过（比如写谱辅助直接改了文件），编辑器一秒内就会发现，弹窗问要不要「重新载入」；选「保留编辑器里的」就继续用编辑器里的版本。顶栏也有「重新载入」按钮。保存前发现文件被改过会先问你，免得把外面的改动盖掉。重新载入后按 Ctrl+Z 能回到载入前编辑器里的版本。

## 代码结构（开发者）

`core/src/main/java/org/kelvinizer/charter/`

| 类 | 作用 |
|---|---|
| `CharterApp` | 程序本体：绘图、输入、在曲库和编辑器之间切换 |
| `LibraryScreen` | 曲库界面：选歌、导入音频、新建难度、试听 |
| `JacketCrop` | 曲绘取景：在整张图上框 16:9 区域和圆形，写进 song.json（图不裁） |
| `EditorScreen` | 编辑器主界面：预览区、时间轴、顶栏、左边工具栏、快捷键 |
| `Inspector` | 右边属性面板：谱面 / 音符 / 场地 / 漩涡 / 水帘 五页 |
| `StatsPanel` | 状态栏「统计」弹出的谱面统计 |
| `Session` | 打开的一个难度：撤销重做、保存、把编辑的音符对应到游戏读出来的音符 |
| `Doc` | 可编辑的谱面数据，读写游戏现在格式的 JSON（旧格式经游戏的 `ChartMapper` 读进来时已换算） |
| `Checks` | 保存前的检查（重复音符、水雷封锁冲突、事件重叠、物件坐标冲突……） |
| `Library` | 谱面文件夹、备份、导入、回收站 |
| `Playback`、`Waveform`、`Mp3Peaks` | 音乐播放和波形（`Mp3Peaks` 用 JLayer 解 MP3，电脑和安卓一样） |
| `Gfx`、`Im` | 画图工具和简单的界面控件（按钮、输入框、下拉框、弹窗） |
| `Platform` | 平台功能接口：选文件、打开文件夹、变速播放（电脑版和安卓版各自实现） |
| `AutoTest` | 自测脚本：加 `-Dkk.autotest=文件夹` 运行，会自动点界面、截图、检查保存后能原样读回 |

- `core/src/main/java/org/kelvinizer/gameplay/CharterPreview.java`：用游戏自己的引擎和画面画预览（自动播放），放在游戏的包里是为了用到游戏画面的内部方法。「实机」用游戏的字体和迷失标记，打包时把游戏的 `assets/fonts/` 和 `assets/ParticleEffects/lost.p` 一起放进 jar 和 APK（`lwjgl3/build.gradle`、`android/build.gradle`），所以安卓版改完要在 Android Studio 里重新 Sync。
- `lwjgl3/`：桌面启动器 `Lwjgl3Launcher` 和 `DesktopPlatform`（Swing 选文件、OpenAL 变速）。
- `android/`：安卓平板启动器 `AndroidLauncher` 和 `AndroidPlatform`（复制 APK 里的谱面、系统文件选择器、MediaPlayer 变速）。平板排版由 `Gfx.tablet()` 打开，各界面按 `Gfx.TABLET` 换位置。

- 代码规范和游戏一样：每行不超过 120 个字；类说明先写一两句中文，再写英文；方法和行内注释用英文。`lwjgl3/` 里的 `StartupHelper` 是 libGDX 自带的文件，不改。

注意：编辑器用到游戏的 `elements`（`Chart`、`ChartMapper`、`Note`…）、`gameplay`（`GameEngine`、`NoteRenderer`…）和 `audio/Mp3Info`。游戏里这些类的方法改名后，编辑器要跟着改，主要是 `CharterPreview`。

旧版编辑器（2026 年 5 月）的代码在 git 的第一次提交里。
