# K & K Charter（谱面编辑器）

K&K 节奏游戏的谱面编辑器。直接打开、保存游戏自己的谱面文件，格式和游戏完全一样：谱面版本 2.0「简单函数」（2026-11-09，Kelvin）。旧格式的谱面打开时自动转成 2.0，保存后变成 2.0。

谱面版本（Kelvin 2026-11-10「谱面版本为2.0，以后谱面版本更改都是0.1 0.1的改」）：现在的谱面格式是 2.0，以后格式每改一次加 0.1（2.1、2.2…）。文件里的 `"format"` 仍写 7，游戏和编辑器的代码里这一版也还叫 v7（`Chart7`、`ChartFormatV7`）；之前的旧格式是 v1–v6。

## 运行

- 游戏文件夹要放在旁边：默认是 `../K and K Rhythm Game`，换位置就改 `gradle.properties` 里的 `gameDir`。
- IntelliJ：打开本文件夹 → 刷新 Gradle → 运行 `lwjgl3 › Tasks › application › run`。命令行：`gradlew lwjgl3:run`。
- 编辑器直接编译游戏的代码（谱面读写、判定线、音符画面），所以预览看到的就是游戏里的样子，保存的文件游戏一定能读。所以编辑器和游戏要一起更新：旧的编辑器读不了新格式的谱面。
- 谱面文件是游戏的谱面版本 2.0（v7，2026-11-09 起，Kelvin「简单函数」，见游戏 `docs/CHART_FORMAT.md` §9）：默认值不写；歌名、曲师、画师、BPM、变速、offset 保存时写进同一个文件夹的 `song.json`（其他键原样保留）。旧格式（v1–v6）打开时用游戏的 `ChartMapper.readOld` 读、`ChartV7Convert` 转成 2.0（海面等 2.0 没有的东西去掉，见 CHART_FORMAT §9.1），编辑器顶上会说明；保存时写成 2.0，原文件先备份。
- 给没有游戏的人用：在本文件夹运行 `gradlew lwjgl3:packageWinX64`（第一次要下载 Java，约 190 MB），得到 `lwjgl3/build/construo/dist/K & K Rhythm Game Charter-winX64.zip`（约 53 MB，带 Java）。解压后双击 exe 就能用，不用装 Java，也不用游戏；Mac、Linux 用 `packageMacM1` / `packageMacX64` / `packageLinuxX64`。只要 jar 的话是 `gradlew lwjgl3:jar`（`lwjgl3/build/libs/`，要装 Java 11 以上）。打包时要有游戏的代码，用的时候不用。
- 旁边没有游戏时，谱面存在程序旁边的 `Charts/`（每首歌一个文件夹：谱面 json、音频、曲绘、song.json），`backups/`、`trash/` 也在程序旁边。把那首歌的整个文件夹压缩成 zip 发给 Kelvin，解压进游戏的 `assets/Charts` 就行。

## 安卓平板版

- 排版按 16:10 平板做（1344 × 840 的画面，右边属性面板和电脑版一样宽），全屏横屏，要 Android 8.0 以上。电脑上加 `-Dkk.tablet=true` 运行可以看平板排版。
- 打包：用 Android Studio 打开本文件夹，等 Gradle 同步完，`Build › Build APK(s)`（或者连上平板直接点运行），APK 在 `android/build/outputs/apk/debug/`。要有 `local.properties`（一行 `sdk.dir=` Android SDK 的位置，可以从游戏文件夹复制）；没有它的时候只编译电脑版，所以打 exe 不用装 Android 的东西。
- 打包时把游戏的 `assets/Charts` 和 `assets/Introduction` 一起放进 APK。平板上第一次打开时复制到应用自己的文件夹 `Android/data/org.kelvinizer.charter/files/`（`Charts/`、`Introduction/`、`backups/`、`trash/` 都在这里）。每首歌只复制一次（记在 `seeded.txt`），平板上改过的不会被新装的 APK 盖掉。
- 把平板上改好的谱面拿回电脑：数据线连电脑，在「内部存储 › Android › data › org.kelvinizer.charter › files › Charts」里复制那首歌的文件夹，放进游戏的 `assets/Charts`。曲库的「打开文件夹」会显示这个位置。
- 操作：一次只认一根手指；点输入框弹出系统键盘；快捷键换成预览下面一排按钮（撤销、重做、复制、粘贴、删除、全选、多选、◀ ▶ 按吸附走一格、统计），「多选」开着时点音符是加选；时间轴左下角 − / + 缩放；返回键回曲库。切到后台时把没保存的修改存一份到 `backups/autosave/`。
- 选音频和曲绘用系统的文件选择器（先复制一份再导入）；变速播放用 Android 的 MediaPlayer，和电脑版一样变速也变调。

## 谱面里有什么（谱面版本 2.0）

Kelvin 2026-11-09 18:44–18:45 定的「简单函数」，详细见游戏 `docs/CHART_FORMAT.md` §9。

- 每个会变的数都是一个函数：一段段「从拍 tᵢ 到 t_f，值从 xᵢ 到 x_f，缓动 e」（e = 1 匀速，2 先慢后快，0.5 先快后慢）。段与段之间、最后一段以后保持上一段的结束值，第一段以前是它的开始值；结束拍不大于开始拍 = 在开始拍直接跳过去。
- 轨道：下落向量 u（键往哪个方向落）、原点 v（底面中心）、底面大小 a（宽 × 长）、天面高度 S 和延申 s、底面高度 F 和延申 f（两个判定面离原点多远，柱子从面再往外伸多长）。出现、消失是宽变成 0 的那几段。透明度 o（1 不透明，0 看不见，用来淡入淡出、调暗；Kelvin 2026-11-09 21:37「加回透明度」）乘到轨道画的所有东西和上面的键。
- 键：位置 h（离它的面多远，最后一段的结束拍就是判定拍）；水流、潮汐（和它们的水雷）还有物件高度 H；浪花、潮汐有跨越的轨道；透明度 o（再乘上轨道的透明度，不影响判定）。假键（Kelvin 2026-11-09 20:37「假键的逻辑倒是可以保留」）和以前一样只画：不判定、不计分、不算 sync，到判定拍（长的到结束）就不画。键还可以有拖拽残影、故障、扭曲（Kelvin 2026-11-10 02:17「故障效果和残影要加上啊，还有那个distortion，这些还是保留」），都按拍分段，只影响画面。
- 漩涡（挡住里面的键，点不到）、水帘（只把里面模糊，不判定）：长方体或椭球体，大小 V、中心 p、朝向 o（深 d 那条边指的方向，默认 (0, 0, 1)，绕中心转过去）。漩涡还可以有故障、扭曲；水帘有模糊强度 b（0–64，默认 16）和扭曲。
- 镜头：位置 P，一直看着原点；默认 P = (0, 0, −6351.24)。视角 fov（上下看得见多少度，默认 11，1 到 150，人眼大约 60°；Kelvin 2026-11-09 22:28「加视角」）也是一个函数。
- 只有垂直判定：键落到它的面上判定。

## 右边的五页

- 「谱面」：曲名、曲师、画师（四个难度共用）、试听段（预览起点、终点，也可以在时间轴的音频条上拖预览框的两条边，按住 Shift 不吸附）；本难度的谱师、定数、迭代次数（每备份一次 +1，游戏不读）；节奏 · 变速（「+ 在当前拍变速」、敲拍测速）、偏移；检查（每一项都能「跳到」相关的键、轨道或漩涡水帘）。
- 「音符」：类型和水雷开关、天面 / 底面、假键开关、轨道（‹ › 换一条）；判定拍、长度；位置 h 一行（播放头的值和段数，点开改分段）、「正常下落 D」「更多下落」（快速、慢速、远处快落、先快后慢、先慢后快、无接近、存下的曲线）、「保存曲线」；物件高度 H；透明度；浪花、潮汐的跨越的轨道；复制、左右镜像、天地互换、删除。真键的分段拍数从判定拍算起（判定拍 = 0），假键用歌里的拍。选了几个键时可以一起改天面 / 底面、假键、整体平移和下落。下面是拖拽残影、故障、扭曲三块：每段有从（拍）、到（拍）（/ = 播放头，× = 不限），「+ 加一段…」加一段，卡片右上的 × 删掉这段；挪键、复制轨道时它们跟着键走。
- 「轨道」：轨道列表、「+ 新建轨道」（从播放头出现）、名字、「选中这条轨道上的 N 个键」、删除轨道；出现、消失（填拍，/ = 播放头；改「出现」时整条轨道连上面判定的键一起挪，假键不动，Kelvin 2026-11-09 17:23），「+ 打完它的键就消失」（最后一个键判定后直接消失，没有淡出，Kelvin 2026-11-09 20:16）；u、v、a、S、s、F、f、透明度每个数都能「+ 分段」，下落向量有「快捷方向」。
- 「镜头」：镜头位置 P、视角；「+ 镜头节点（播放头）」在播放头记下现在的位置，把播放头挪到后面再改数值，镜头就从节点移过去；「回到正前方」。
- 「幕布」：漩涡和水帘的列表、「+ 新建漩涡 / 水帘（播放头）」；漩涡还是水帘、长方体还是椭球体；出现、消失；大小 V（宽、高、深）、中心 p（x、y、z）、朝向 o（x、y、z）。在预览里可以直接拖它们挪中心。水帘还有模糊 b（能「+ 分段」）；下面漩涡有故障、扭曲，水帘有扭曲，写法和音符页一样。

## 预览

- 中间的预览就是游戏自己画的画面：游戏的 `ChartV7Runtime` 把正在改的谱面建成游戏的谱面，`CharterPreview` 用游戏的引擎和画面画出来（自动播放）。编辑器只在上面画选中的框、长条的手柄、轨道名、坐标轴和按钮，用的是和游戏同一个镜头（`Scene`）。
- 右上角的视角方块（Kelvin 2026-11-09 20:02「六个视角并成一个魔方一样的东西放在右上角」，20:35「可以点击边和角，稍微做的圆滑一点点」）：方块跟着视角转；点一面、一条边或一个角就从那边看（6 个面、12 条边、8 个角）；正对一面时四周的小箭头转到旁边那一面；在方块上拖动 = 转视角；下面的「归位」回到谱面自己的镜头。转视角只在编辑时，不存进谱面，左上角写着现在的视角。
- 方块右边一列（Kelvin 2026-11-09 20:16；11-10 02:15 和方块换了位置，按钮贴着右边）：「⇆ 实机」（像游戏的自动播放一样画分数、连击、判定、进度条、难度和时间，不能编辑）、「+镜头节点」、「sync」（高亮 / 增强 / 关，和游戏设置里的 SYNC HINT 一样，只影响预览）、「显示：坐标系」（x 红、y 绿、z 蓝，从原点各 960）、「显示：假键」（打开后假键画在时间轴上、在预览里点得到；默认关，游戏画面里一直有）、「显示：名称 / 编号」（轨道下面和轨道格子里写名字还是编号，没起名字的轨道两样都是编号；Kelvin 2026-11-10 04:54「有点乱，显示的时候可以选择显示编号或者名称吧」）。
- 选择工具：点键选中（Ctrl / Shift 加选），顺着它的轨道拖改判定拍，拖长条远端的手柄改长度；按在轨道上（不是键上）拖 = 在正对你的平面里挪轨道的原点。

## 时间轴和状态栏

- 天面、底面两行是键（按判定拍排），拖动框选，拖键改时间。「函数」行是右边那一页正在改的东西（轨道、键、镜头、漩涡水帘）的分段；「曲线 ›」打开曲线窗口：拖点改拍和数值，双击加点，Delete 合并两段或删掉一段。
- 音频行：左右拖着走时间（单击 = 跳到那里），左边的下拉框选声部。上面的橙色标记是变速，青色条是游戏的试听段。
- 状态栏右下角「统计」：各种键的数量（分天面 / 底面）、物量（计分的键，不含水雷）、sync、各种函数的分段数、轨道、变速、漩涡水帘和假键的个数、时长和密度。⚠ 是检查发现的问题数。

## 其他

- 声部分析（Kelvin 2026-11-07 19:51「分离比较显著的声部」）：时间轴「音频」行左边的下拉框选 原曲 / 鼓 / 低音 / 旋律。某首歌第一次选声部时在后台分析（几秒到几十秒，那一行显示进度），结果存在编辑器文件夹的 voices 里（每首歌一个子文件夹：drums.wav、bass.wav、melody.wav、analysis.bin），音频文件不变就直接读，删掉也没关系（下次重新算）。选了声部，播放器只放这个声部（时间和播放状态不变），那一行画它的响度、起音点（竖线，越亮越强）和旋律的音高（点，越高音越高）。不是 AI 分离：中值滤波把打击声（鼓）和持续的音分开，持续的音再按 250 Hz 左右分成低音和旋律，所以底鼓的低频有时会落进低音，人声和主旋律乐器算在一起。
- 右边的编辑栏：滚轮、拖最右边的滚动条（点滚动条空的地方直接跳过去）、按住空白处上下拖，都能滚动。
- 数字框里打 `/` = 播放头那一刻。
- 曲库最后一行（「练习谱」里）是「新手教程 · …」：游戏的新手教程（Charts 旁边的 `assets/Introduction`，由 Charts/index.json 的 `"tutorial"` 指定），带它的音乐，直接改原来的文件，备份在 `backups/Introduction`。它不能在编辑器里删除，也别把它搬进 Charts（游戏会把它当成一首单曲）。
- 难度在编辑器里和游戏一样显示为 Shallow / Medium / Deep / Abyss（Kelvin 2026-10-27 改名）；谱面文件名从 2026-11-10 起和显示一样：`Shallow.json` / `Medium.json` / `Deep.json` / `Abyss.json`（Kelvin「把谱面文件的名字也都统一改了」，游戏 7.233 起两种都认）。还是旧文件名（有 `Surface.json`）的歌，编辑器第一次读到时改名：先 `Shallow.json` → `Medium.json`，再 `Surface.json` → `Shallow.json`，游戏 `assets.txt` 里这两行跟着改（`Library.renameCharts`）；文件夹里已经有 `Medium.json`（旧命名不读它）或改名失败时保持旧名字，照旧命名读写。
- 曲库不列 Song 1–5（Kelvin 2026-11-01，`Library.HIDDEN`）；它们的文件夹不动，自测时照常列出。
- 曲库下面的「练习谱」（Kelvin 2026-11-02，`Library.PRACTICE`）：和上面的单曲分开，依次是主线的 Aleph-0、marsh mally（游戏 Charts 里的，不能在编辑器里删除），Charter 自己 `practice/` 文件夹里的歌（Altale，游戏里没有），最后是新手教程。
- 「导入音频」新建一首歌（Kelvin 2026-10-22）：填好文件夹名和 BPM 后直接建好 Shallow、Medium、Deep 三个空谱面（定数 1、2、3），并打开 Shallow。还没有谱面的歌在曲库里点「+ 新建」也一样（点的是 Abyss 就再加一个 Abyss 并打开它）。之后单独新建的空白 Shallow / Medium / Deep 也用这三个定数，Abyss 是 1。
- 曲库里点曲绘可以换图（png / jpg），选好后先打开「曲绘取景」（Kelvin 2026-10-21：「有些曲绘不是16：9就需要我选定区域，圆形部分也要我选定」）：在整张图上拖一个 16:9 的框（选歌卡片、结算显示这一块）和一个圆（地图上的洞、进歌时的转场显示这个圆），右上的按钮或 Tab 换框，拖框移动，拖角上的点或滚轮调大小，「重置」= 居中最大，右边预览两处的样子。确定后图片原样复制成 `jacket.<扩展名>`（不裁），旧的 `jacket.*` 移到 `trash/`；两个框按图片宽、高的比例写进 song.json：`"jacket16x9"` 和 `"jacketCircle"`（圆外接的正方形），都是 `{"x", "y", "w", "h"}`，`y` 从上往下量。框是居中最大的就不写（游戏没有框时就居中裁）。歌曲详情里的「曲绘取景」按钮随时改现在这张曲绘的两个框。曲库列表和详情里的方形曲绘显示圆外接的正方形。
- 谱面文件在编辑器外被改过（比如写谱辅助直接改了文件），编辑器一秒内就会发现，弹窗问要不要「重新载入」；选「保留编辑器里的」就继续用编辑器里的版本。顶栏也有「重新载入」按钮。保存前发现文件被改过会先问你，免得把外面的改动盖掉。重新载入后按 Ctrl+Z 能回到载入前编辑器里的版本。
- 音频比谱面短时（比如现在用 Aleph-0 占位的歌），音乐放完后时间照样走，一直播到最后一个音符，只是没有声音。

## 代码结构（开发者）

`core/src/main/java/org/kelvinizer/charter/`

| 类 | 作用 |
|---|---|
| `CharterApp` | 程序本体：绘图、输入、在曲库和编辑器之间切换 |
| `LibraryScreen` | 曲库界面：选歌、导入音频、新建难度、试听 |
| `JacketCrop` | 曲绘取景：在整张图上框 16:9 区域和圆形，写进 song.json（图不裁） |
| `EditorScreen` | 编辑器主界面：预览区（游戏画面、选中框、视角方块）、时间轴、顶栏、左边工具栏、快捷键 |
| `Scene` | 编辑器的三维投影，和游戏同一个镜头（看着原点、11°）：点选、拖动、坐标轴、26 个视角都用它 |
| `Inspector` | 右边属性面板：谱面 / 音符 / 轨道 / 镜头 / 幕布 五页 |
| `CurvePanel` | 曲线窗口：改一个函数的分段（拖点、双击加点、Delete 合并或删掉一段） |
| `StatsPanel` | 状态栏「统计」弹出的谱面统计 |
| `Session` | 打开的一个难度：撤销重做、保存、选中的键 / 轨道 / 漩涡水帘，预览用的游戏谱面（`ChartV7Runtime` 建） |
| `Doc` | 可编辑的 2.0 谱面（游戏的 `Chart7`：轨道、键、漩涡水帘、镜头）和歌曲信息，读写用游戏的 `ChartFormatV7` |
| `Checks` | 谱面检查（键的轨道不存在、浪花潮汐没跨轨道、没有下落分段、长度为 0、判定时轨道宽为 0、叠键、判定时不在面上） |
| `Library` | 谱面文件夹、备份、导入、回收站、旧格式转 2.0、存下的曲线 |
| `Playback`、`Waveform`、`Mp3Peaks`、`VoiceSplit` | 音乐播放、波形、声部分析（`Mp3Peaks` 用 JLayer 解 MP3，电脑和安卓一样） |
| `Gfx`、`Im` | 画图工具和简单的界面控件（按钮、输入框、下拉框、弹窗） |
| `Platform` | 平台功能接口：选文件、打开文件夹、变速播放（电脑版和安卓版各自实现） |
| `AutoTest` | 自测脚本：加 `-Dkk.autotest=文件夹` 运行，写一张测试谱，放键、拖键、撤销重做、复制轨道、点视角方块、统计、检查、假键、保存读回、打开旧谱，截图并记日志 |

- `core/src/main/java/org/kelvinizer/gameplay/CharterPreview.java`：用游戏自己的引擎和画面画预览（自动播放），放在游戏的包里是为了用到游戏画面的内部方法。「实机」用游戏的字体和迷失标记，打包时把游戏的 `assets/fonts/` 和 `assets/ParticleEffects/lost.p` 一起放进 jar 和 APK（`lwjgl3/build.gradle`、`android/build.gradle`），所以安卓版改完要在 Android Studio 里重新 Sync。
- `lwjgl3/`：桌面启动器 `Lwjgl3Launcher` 和 `DesktopPlatform`（Swing 选文件、OpenAL 变速）。
- `android/`：安卓平板启动器 `AndroidLauncher` 和 `AndroidPlatform`（复制 APK 里的谱面、系统文件选择器、MediaPlayer 变速）。平板排版由 `Gfx.tablet()` 打开，各界面按 `Gfx.TABLET` 换位置。

- 代码规范和游戏一样：每行不超过 120 个字；类说明先写一两句中文，再写英文；方法和行内注释用英文。`lwjgl3/` 里的 `StartupHelper` 是 libGDX 自带的文件，不改。

注意：编辑器用到游戏的 `elements`（`Chart7`、`Key7`、`Lane7`、`ChartFormatV7`、`ChartV7Convert`、`ChartV7Runtime`、`ChartMapper`…）、`gameplay`（`GameEngine`、`NoteRenderer`…）和 `audio/Mp3Info`。游戏里这些类的方法改名后，编辑器要跟着改，主要是 `CharterPreview`。

旧版编辑器（2026 年 5 月）的代码在 git 的第一次提交里。
