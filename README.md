# K & K Charter（谱面编辑器）

K&K 节奏游戏的谱面编辑器。直接打开、保存游戏自己的谱面文件，格式和游戏完全一样：谱面版本 2.1（2.0「简单函数」2026-11-09；2.1 加上轨道的法向量 n、水雷 m、轨道本身 l 和组，2026-11-10、11，Kelvin）。2.0、写成 "2.2" 的（2026-11-11 晚上的编辑器存的）、文件里 format 还写成数字的和更旧格式（v1–v6）的谱第一次打开时自动存成 2.1，原文件先备份到 backups（Kelvin 2026-11-11「别人换新编辑器的时候，第一次打开自动刷新成最新版本」）。

谱面版本（Kelvin 2026-11-10「谱面版本为2.0，以后谱面版本更改都是0.1 0.1的改」，2026-11-11「文件里的format也改成2.0，现在既然加了一个东西就改为2.1」）：文件里直接写版本号，现在是 `"format": "2.1"`（2.1 加了轨道的法向量 n、水雷 m、轨道本身 l 和组），以后格式每改一次加 0.1。以前的文件写数字（7 是 2.0，8、9 是 2.1），照样能读；写成 "2.2" 的也当 2.1 读（Kelvin 2026-11-12「2.2文件记得读取的时候全部把版本调回2.1」）。

制谱器版本号就是谱面版本（Kelvin 2026-11-12「制谱器版本号，format都放在2.1」「这两个要始终同步的」）：现在是 2.1，窗口标题写着（`K & K Charter 2.1`，直接取游戏的 `ChartFormatV7.VERSION`），jar 叫 `K & K Rhythm Game Charter-2.1.jar`，安卓版的版本名也是它（都来自 `gradle.properties` 的 `projectVersion`）。谱面格式升级时 `projectVersion` 跟着改，自测会检查两个一样。游戏和编辑器的代码里这一版仍叫 v7（`Chart7`、`ChartFormatV7`）；之前的旧格式是 v1–v6。

## 运行

- 游戏文件夹要放在旁边：默认是 `../K and K Rhythm Game`，换位置就改 `gradle.properties` 里的 `gameDir`。
- IntelliJ：打开本文件夹 → 刷新 Gradle → 运行 `lwjgl3 › Tasks › application › run`。命令行：`gradlew lwjgl3:run`。
- 编辑器直接编译游戏的代码（谱面读写、判定线、音符画面），所以预览看到的就是游戏里的样子，保存的文件游戏一定能读。所以编辑器和游戏要一起更新：旧的编辑器读不了新格式的谱面。
- 谱面文件是游戏的谱面版本 2.1（v7，2026-11-09 起，Kelvin「简单函数」，见游戏 `docs/CHART_FORMAT.md` §9）：默认值不写；歌名、曲师、画师、BPM、变速、offset 保存时写进同一个文件夹的 `song.json`（其他键原样保留）。旧格式（v1–v6）打开时用游戏的 `ChartMapper.readOld` 读、`ChartV7Convert` 转成 2.1（海面等没有的东西去掉，见 CHART_FORMAT §9.1；键自己的横移、旋转、公转放在不画出来的载体轨道上照旧动，编辑器把这些轨道叫「载体 1」「载体 2」…，单独把键拖到别的轨道就不跟着动了），编辑器顶上会说明，第一次打开就存成 2.1，原文件先备份。
- 给没有游戏的人用：在本文件夹运行 `gradlew lwjgl3:packageWinX64`（第一次要下载 Java，约 190 MB），得到 `lwjgl3/build/construo/dist/K & K Rhythm Game Charter-winX64.zip`（约 53 MB，带 Java）。解压后双击 exe 就能用，不用装 Java，也不用游戏；Mac、Linux 用 `packageMacM1` / `packageMacX64` / `packageLinuxX64`。只要 jar 的话是 `gradlew lwjgl3:jar`（`lwjgl3/build/libs/`，要装 Java 11 以上）。打包时要有游戏的代码，用的时候不用。
- 旁边没有游戏时，谱面存在程序旁边的 `Charts/`（每首歌一个文件夹：谱面 json、音频、曲绘、song.json），`backups/`、`trash/` 也在程序旁边。把那首歌的整个文件夹压缩成 zip 发给 Kelvin，解压进游戏的 `assets/Charts` 就行。

## 安卓平板版

- 排版按 16:10 平板做（1344 × 840 的画面，右边属性面板和电脑版一样宽），全屏横屏，要 Android 8.0 以上。电脑上加 `-Dkk.tablet=true` 运行可以看平板排版。
- 打包：用 Android Studio 打开本文件夹，等 Gradle 同步完，`Build › Build APK(s)`（或者连上平板直接点运行），APK 在 `android/build/outputs/apk/debug/`。要有 `local.properties`（一行 `sdk.dir=` Android SDK 的位置，可以从游戏文件夹复制）；没有它的时候只编译电脑版，所以打 exe 不用装 Android 的东西。
- 打包时把游戏的 `assets/Charts` 和 `assets/Introduction` 一起放进 APK。平板上第一次打开时复制到应用自己的文件夹 `Android/data/org.kelvinizer.charter/files/`（`Charts/`、`Introduction/`、`backups/`、`trash/` 都在这里）。每首歌只复制一次（记在 `seeded.txt`），平板上改过的不会被新装的 APK 盖掉。
- 把平板上改好的谱面拿回电脑：数据线连电脑，在「内部存储 › Android › data › org.kelvinizer.charter › files › Charts」里复制那首歌的文件夹，放进游戏的 `assets/Charts`。曲库的「打开文件夹」会显示这个位置。
- 操作：一次只认一根手指；点输入框弹出系统键盘；快捷键换成预览下面一排按钮（撤销、重做、复制、粘贴、删除、全选、多选、◀ ▶ 按吸附走一格、统计），「多选」开着时点音符是加选；时间轴左下角 − / + 缩放；返回键回曲库。切到后台时把没保存的修改存一份到 `backups/autosave/`。
- 选音频和曲绘用系统的文件选择器（先复制一份再导入）；变速播放用 Android 的 MediaPlayer，和电脑版一样变速也变调。

## 谱面里有什么（谱面版本 2.1）

Kelvin 2026-11-09 18:44–18:45 定的「简单函数」，详细见游戏 `docs/CHART_FORMAT.md` §9。

- 每个会变的数都是一个函数：一段段「从拍 tᵢ 到 t_f，值从 xᵢ 到 x_f，缓动 e」（e = 1 匀速，2 先慢后快，0.5 先快后慢）。段与段之间、最后一段以后保持上一段的结束值，第一段以前是它的开始值；结束拍不大于开始拍 = 在开始拍直接跳过去。
- 轨道：下落向量 u（键往哪个方向落）、法向量 n（轨道正面朝哪边，Kelvin 2026-11-10「那就加一个法向量朝向」「和下落向量一样」：轨道绕自己的向上轴转，让正面尽量朝 n；不写就是朝你，按最短的转法转到下落方向，和以前一样）、原点 v（底面中心）、底面大小 a（宽 × 长）、天面高度 S 和延申 s、底面高度 F 和延申 f（两个判定面离原点多远，柱子从面再往外伸多长）。出现、消失是宽变成 0 的那几段。透明度 o（1 不透明，0 看不见，用来淡入淡出、调暗；Kelvin 2026-11-09 21:37「加回透明度」）乘到轨道画的所有东西和上面的键。水雷 m，也叫红色轨道（Kelvin 2026-11-10 23:01「在一定时间内（一维事件）这些轨道会变红」；2026-11-12 06:08 改成「红色轨道（水雷轨道）：按到了，没有键，不加分，不断连击，不报lost，但是落在这种轨道上的键只能打出resonance」）：大于 0 的时候整条轨道变红，1 最红，强制严判：天面、底面上的键都只能打出 RESONANCE，按到没有键不扣分、不断连击、不报 LOST，也不算水雷；默认 0 不写。浪花水雷、潮汐水雷照留，水雷轨道是另一种（Kelvin 2026-11-11 01:48「我觉得还是保留浪花水雷和潮汐水雷吧，整个红色轨道作为另一种性质」）。轨道本身 l（Kelvin 2026-11-11 02:12「这种浪花水雷理论上也不能出现轨道」）：只乘到轨道自己画的东西（柱子、面、判定线、边、光、变红），不乘到上面的键；0 就是只显示键，用来放只当图案的键；默认 1 不写。
- 键：位置 h（离它的面多远，最后一段的结束拍就是判定拍）；水流、潮汐（和它们的水雷）还有物件高度 H；浪花、潮汐有跨越的轨道；透明度 o（再乘上轨道的透明度，不影响判定）。假键（Kelvin 2026-11-09 20:37「假键的逻辑倒是可以保留」）和以前一样只画：不判定、不计分、不算 sync，到判定拍（长的到结束）就不画。键还可以有拖拽残影、故障、扭曲（Kelvin 2026-11-10 02:17「故障效果和残影要加上啊，还有那个distortion，这些还是保留」），都按拍分段，只影响画面。
- 漩涡（挡住里面的键，点不到）、水帘（只把里面模糊，不判定）：长方体或椭球体，大小 V、中心 p、朝向 o（深 d 那条边指的方向，默认 (0, 0, 1)，绕中心转过去）。漩涡还可以有故障、扭曲；水帘有模糊强度 b（0–64，默认 16）和扭曲。
- 镜头：位置 P，一直看着原点；默认 P = (0, 0, −6351.24)。视角 fov（上下看得见多少度，默认 11，1 到 150，人眼大约 60°；Kelvin 2026-11-09 22:28「加视角」）也是一个函数。
- 只有垂直判定：键落到它的面上判定。
- 组（谱面 2.1，Kelvin 2026-11-11 16:39「轨道一多怎么办？…有点像CAD？」，17:32「可以」）：几条轨道（和别的组）收在一起，有名字、中心位置、旋转（绕 x、y、z 的度数，先转 z，再转 x，最后转 y）、缩放和透明度，都是函数。组里的轨道的原点、下落向量、法向量按组的坐标写，组移动、转、缩放时整个跟着（键也跟着）；组可以套组。2026-11-11 晚上存成 "2.2" 的谱打开时改回 2.1（只改版本号）。

## 右边的六页

- 「谱面」：曲名、曲师、画师（四个难度共用）、试听段（预览起点、终点，也可以在时间轴的音频条上拖预览框的两条边，按住 Shift 不吸附）；本难度的谱师、定数、迭代次数（每备份一次 +1，游戏不读）；节奏 · 变速（「+ 在当前拍变速」、敲拍测速）、偏移；检查（每一项都能「跳到」相关的键、轨道或漩涡水帘）。
- 「音符」：类型和水雷开关、天面 / 底面、假键开关、轨道（‹ › 换一条）；判定拍、长度；位置 h 一行（播放头的值和段数，点开改分段）、「正常下落 D」「更多下落」（快速、慢速、远处快落、先快后慢、先慢后快、无接近、存下的曲线）、「保存曲线」；物件高度 H；透明度；浪花、潮汐的跨越的轨道；复制、左右镜像、天地互换、删除。真键的分段拍数从判定拍算起（判定拍 = 0），假键用歌里的拍。选了几个键时可以一起改天面 / 底面、假键、整体平移和下落。下面是拖拽残影、故障、扭曲三块：每段有从（拍）、到（拍）（/ = 播放头，× = 不限），「+ 加一段…」加一段，卡片右上的 × 删掉这段；挪键、复制轨道时它们跟着键走。
- 「轨道」：轨道列表、「+ 新建轨道」（从播放头出现）、名字、「选中这条轨道上的 N 个键」、删除轨道；出现、消失（填拍，/ = 播放头；改「出现」时整条轨道连上面判定的键一起挪，假键不动，Kelvin 2026-11-09 17:23），「+ 打完它的键就消失」（最后一个键判定后直接消失，没有淡出，Kelvin 2026-11-09 20:16）；u、n、v、a、S、s、F、f、透明度、轨道本身、水雷每个数都能「+ 分段」，「只显示键（轨道本身不画）」一键把轨道本身设成 0（再按一次回到 1），下落向量和法向量都有「快捷方向」；水雷下面的「+ 从播放头变红 1 拍」从播放头加一拍红（结束拍在段里改）。
- 「镜头」：镜头位置 P、视角；「+ 镜头节点（播放头）」在播放头记下现在的位置，把播放头挪到后面再改数值，镜头就从节点移过去；「回到正前方」。
- 「场景」（Kelvin 2026-11-11 16:39「是不是应该建立一个3D建模的界面来自定义一个3D场景，有点像CAD？」，17:32「可以，然后记得保存建模，以及后面可以导入建模之类的」）：左边一列换成场景的工具：选择 N、方块 B、阵列、镜像、成组 Ctrl+G（放键的工具在其他页，选一个放键的工具就回到「音符」页）。选中一个组时是组的卡片：名字、「进组」、「解组」、「保存为模型」，位置 x y z（组的中心）、旋转 x y z（度，绕中心）、缩放、透明度，每个数都能「+ 分段」、在播放头改就自动记关键帧；选中一条轨道时是它的轨道卡片（和「轨道」页一样）；什么都没选时说明怎么用，下面是「导入模型」。解组 = 组里的东西放回外面一层，留在原地（位置、朝向、大小、键的下落都换算过去）；组在动（有分段），或者组转过而里面的东西又在动、在转，就不解，提示先去掉分段或把旋转改回 0。
  - 方块：在预览的网格上点一下放一个 240 × 240 × 240 的方块，就是一条新轨道（放在现在进的组里，和「+ 新建轨道」一样从播放头出现），放好就选中它。
  - 阵列：先选中轨道或组，点「阵列」，右边换成阵列的卡片：一行（每个隔 x y z）或一圈（一共转多少度、绕哪个轴、绕哪个中心：原点或同一层别的组的中心；360 度是一整圈，不到 360 度时两头都有一个），数量包括原来这个，放进新组（名字自动起，一圈时新组的中心就是圈的中心）或不放进组。确定之前预览里是橙色的虚线影子；Enter 确定、Esc 取消。复制出来的轨道和原来的一样，不带键。正在动、在转的东西不能排一圈（提示先成组，再排这个组）。
  - 镜像：选中的东西按 x = 0 左右对称复制一份（不带键），原来的不动，选中复制出来的。Ctrl+D 复制一份，往 x 挪一格网格。
  - 模型：组的卡片上「保存为模型」把这个组连里面的轨道和小组（不带键）存进 Charter 文件夹的 `models/`，同名的换掉；所有谱的「场景」页都能「导入模型」，导进来是一个新组（新的编号，名字重了自动加数字），放在现在进的组（或谱面）的原点。
- 「幕布」：漩涡和水帘的列表、「+ 新建漩涡 / 水帘（播放头）」；漩涡还是水帘、长方体还是椭球体；出现、消失；大小 V（宽、高、深）、中心 p（x、y、z）、朝向 o（x、y、z）。在预览里可以直接拖它们挪中心。水帘还有模糊 b（能「+ 分段」）；下面漩涡有故障、扭曲，水帘有扭曲，写法和音符页一样。

## 预览

- 中间的预览就是游戏自己画的画面：游戏的 `ChartV7Runtime` 把正在改的谱面建成游戏的谱面，`CharterPreview` 用游戏的引擎和画面画出来（自动播放）。编辑器只在上面画选中的框、长条的手柄、轨道名、坐标轴和按钮，用的是和游戏同一个镜头（`Scene`）。
- 预览靠左（Kelvin 2026-11-11 21:10「现在16：10好像会导致中间显示区域有留白。把其中一些元素挪过去」，21:52「可以」）：预览一直是游戏的 16:10，放在左边工具栏旁边，右边空出来的那条放视角方块、「归位」和按钮一列，下面写着第几拍、视角（挪过视角、在「轨道」页选着轨道时也写在这里）。那条窄的时候方块在按钮上面，宽的时候（时间轴拉高）两个并排；预览拉到最大、那条放不下时，它们照旧压在画面右上角，第几拍写在画面左上角。
- 视角方块（Kelvin 2026-11-09 20:02「六个视角并成一个魔方一样的东西放在右上角」，20:35「可以点击边和角，稍微做的圆滑一点点」）：方块跟着视角转；点一面、一条边或一个角就从那边看（6 个面、12 条边、8 个角）；正对一面时四周的小箭头转到旁边那一面；在方块上拖动 = 转视角；下面的「归位」回到谱面自己的镜头。转视角只在编辑时，不存进谱面，左上角写着现在的视角。
- 按钮一列（Kelvin 2026-11-09 20:16；11-10 02:15 和方块换了位置，放在方块右边或下面）：「⇆ 实机」（像游戏的自动播放一样画分数、连击、判定、进度条、难度和时间，不能编辑）、「+镜头节点」、「sync」（高亮 / 增强 / 关，和游戏设置里的 SYNC HINT 一样，只影响预览）、「显示：坐标系」（x 红、y 绿、z 蓝，从原点各 960）、「显示：假键」（打开后假键画在时间轴上、在预览里点得到；默认关，游戏画面里一直有）、「显示：名称 / 编号」（轨道下面和轨道格子里写名字还是编号，没起名字的轨道两样都是编号；Kelvin 2026-11-10 04:54「有点乱，显示的时候可以选择显示编号或者名称吧」）。
- 选择工具：点键选中（Ctrl / Shift 加选），顺着它的轨道拖改判定拍，拖长条远端的手柄改长度；按在轨道上（不是键上）拖 = 在正对你的平面里挪轨道的原点。
- 「场景」页的预览：画网格（组的地面那一层，预览右上角那列按钮里的「网格 ▾」选 25 / 50 / 100 / 200 / 500 或关），放方块、拖箭头、拖轨道和组都对齐网格。选中的东西上有手柄：拖红绿蓝箭头 = 沿 x / y / z 挪（按它所在的组的坐标），拖黄圈 = 绕竖直轴转（只有组有，整度数），拖中间的白色小方块 = 左右拖着缩放（组改缩放，轨道改宽、长和高）。都是在播放头改，和右边改数值一样自动记关键帧。这一页点不到键，点空白处 = 什么都不选。
- 组：点组里的轨道 = 选中整个组（整组变青色，中心画一个圈和组名），拖 = 挪整个组；双击 = 进组（组外的东西变淡），再点才是单条轨道（或里面的小组），Esc 或点组外面就出组。按住 Shift 点 = 多选轨道和组，Ctrl+G 成组（新组的中心在它们中间，谁都不动）。组里的轨道照旧能放键、拖键、拖原点（按组的坐标换算）。

## 时间轴和状态栏

- 关键帧和分层时间轴（Kelvin 2026-11-11 16:15「我要它有点像3D动画制作的那种」，16:39「基本可以」）：
  - 顶栏「◇+ 关键帧」（K）：在播放头（按吸附）给选中的东西记一个关键帧，值不变：轨道 = 原点 v、下落向量 u、宽长 a；镜头 = 位置 P 和视角；漩涡 / 水帘 = 中心和大小；一个键 = 位置 h。播放头已经在关键帧上时按钮是「◆− 关键帧」，按了就去掉它（前后两段并成一段）。键的判定拍去不掉，判定拍以后加不了；出现、消失那几段不算关键帧。挪了播放头以后在右边改数值、在预览里拖，照旧自动在播放头记关键帧。
  - 预览和时间轴中间的线可以上下拖（时间轴高一点 ↔ 预览大一点）。
  - 最上面是尺子（播放头的拍在方框里，拖尺子走时间），左边「只看选中」、「搜索轨道」（名字或编号）、「曲线 ›」；下面是音频行。
  - 一行一行：「总览」（所有键，天面的短线在上、底面的在下，还有所有关键帧 ◆；点一下跳过去）、「镜头」、「无轨键」（有才列）、每条轨道一层（名字，右边「轨道 N」）、每个漩涡 / 水帘一层。▸ / ▾ 展开；在预览或右边选中一个东西，它那一层自动展开并滚出来。层里的横条是它出现到消失：拖两头改出现、消失；拖整条 = 改「出现」，整条轨道连判定的键一起挪（假键不动）。
  - 轨道展开后：「天面键」「地面键」两行只有这条轨道的键，以前天面 / 底面两行的操作（点选、拖键改时间、框选、Delete、复制…）照旧；拿着放键的工具在空白处点一下 = 在那一拍给这条轨道的这个面放一个键（不用 Tab）。下面每组会动的数一行（原点 v、下落向量 u、宽长 a…，x、y、z 在同一行）：◆ 是关键帧，点一下跳过去，拖动改时间（不越过旁边的 ◆），播放头上的 ◆ 带白圈；两个 ◆ 之间的紫条是一段，点它在上面打开缓动条（先快后慢 e 0.33 / 0.5、匀速 e 1、先慢后快 e 2 / 3，一点就用；「自定义」填任意大于 0 的 e）。「＋ 加一行」给还没分段的数（透明度、天面高度…）在播放头加一个点。选中一个键时，它自己的 h、H、透明度也列在它的轨道下面。
  - 组（谱面 2.1）一组一层，名字后面有「组」字、右边是里面有几条轨道；展开后是它的位置、旋转（、缩放、透明度）几行和「＋ 加一行」，下面是里面的小组和轨道（往里缩一点）。不在组里的轨道排在组后面。「只看选中」「搜索轨道」时不分组，列成一排。
  - 右边面板里，在播放头有关键帧的数框是琥珀色的，写「◆ 播放头」；选中一个东西时预览里画出它在每个关键帧的样子（琥珀色的影子、「① 0 拍」这样的编号，同一个地方的写在一起，中间是带箭头的虚线）。
- 「曲线 ›」打开曲线窗口：拖点改拍和数值，双击加点，Delete 合并两段或删掉一段。
- 音频行：左右拖着走时间（单击 = 跳到那里），左边的下拉框选声部。上面的橙色标记是变速，青色条是游戏的试听段。
- 状态栏右下角「统计」：各种键的数量（分天面 / 底面）、物量（计分的键，不含水雷）、sync、各种函数的分段数、轨道、变速、漩涡水帘和假键的个数、时长和密度。⚠ 是检查发现的问题数。

## 其他

- 声部分析（Kelvin 2026-11-07 19:51「分离比较显著的声部」）：时间轴「音频」行左边的下拉框选 原曲 / 鼓 / 低音 / 旋律。某首歌第一次选声部时在后台分析（几秒到几十秒，那一行显示进度），结果存在编辑器文件夹的 voices 里（每首歌一个子文件夹：drums.wav、bass.wav、melody.wav、analysis.bin），音频文件不变就直接读，删掉也没关系（下次重新算）。选了声部，播放器只放这个声部（时间和播放状态不变），那一行画它的响度、起音点（竖线，越亮越强）和旋律的音高（点，越高音越高）。不是 AI 分离：中值滤波把打击声（鼓）和持续的音分开，持续的音再按 250 Hz 左右分成低音和旋律，所以底鼓的低频有时会落进低音，人声和主旋律乐器算在一起。
- 右边的编辑栏：滚轮、拖最右边的滚动条（点滚动条空的地方直接跳过去）、按住空白处上下拖，都能滚动。

- 曲库里点曲绘可以换图（png / jpg），选好后先打开「曲绘取景」（Kelvin 2026-10-21：「有些曲绘不是16：9就需要我选定区域，圆形部分也要我选定」）：在整张图上拖一个 16:9 的框（选歌卡片、结算显示这一块）和一个圆（地图上的洞、进歌时的转场显示这个圆），右上的按钮或 Tab 换框，拖框移动，拖角上的点或滚轮调大小，「重置」= 居中最大，右边预览两处的样子。确定后图片原样复制成 `jacket.<扩展名>`（不裁），旧的 `jacket.*` 移到 `trash/`；两个框按图片宽、高的比例写进 song.json：`"jacket16x9"` 和 `"jacketCircle"`（圆外接的正方形），都是 `{"x", "y", "w", "h"}`，`y` 从上往下量。框是居中最大的就不写（游戏没有框时就居中裁）。歌曲详情里的「曲绘取景」按钮随时改现在这张曲绘的两个框。曲库列表和详情里的方形曲绘显示圆外接的正方形。

## 代码结构（开发者）

`core/src/main/java/org/kelvinizer/charter/`

| 类 | 作用 |
|---|---|
| `CharterApp` | 程序本体：绘图、输入、在曲库和编辑器之间切换 |
| `LibraryScreen` | 曲库界面：选歌、导入音频、新建难度、试听 |
| `JacketCrop` | 曲绘取景：在整张图上框 16:9 区域和圆形，写进 song.json（图不裁） |

| `Scene` | 编辑器的三维投影，和游戏同一个镜头（看着原点、11°）：点选、拖动、坐标轴、26 个视角都用它；组里的轨道按组摆（游戏的 `Group7.Pose`） |

| `Layers` | 分层时间轴：总览、镜头、无轨键、每个组、每条轨道和漩涡水帘一层（组里的东西在组下面；天面键 / 地面键、会动的数、出现到消失的横条、缓动条） |
| `SceneTools` | 「场景」页的工具：网格、手柄（箭头、圈、白方块）、放方块、阵列（影子、确定）、镜像、Ctrl+D、存模型和导入模型 |
| `Keyframes` | 关键帧：一起改的几个数（时间轴的一行、「关键帧」按钮管的那些）加点、去点、挪点、改一段的缓动 |
| `StatsPanel` | 状态栏「统计」弹出的谱面统计 |
| `Session` | 打开的一个难度：撤销重做、保存、选中的键 / 轨道 / 漩涡水帘，预览用的游戏谱面（`ChartV7Runtime` 建） |
| `Doc` | 可编辑的 2.1 谱面（游戏的 `Chart7`：轨道、键、漩涡水帘、镜头、组）和歌曲信息，读写用游戏的 `ChartFormatV7`；成组、解组；场景页的复制（不带键）、挪、转、镜像，模型的写出和导入 |

| `Library` | 谱面文件夹、备份、导入、回收站、旧格式转 2.1（载体轨道起名）、存下的曲线、模型（`models/`） |

| `Gfx`、`Im` | 画图工具和简单的界面控件（按钮、输入框、下拉框、弹窗） |

- `lwjgl3/`：桌面启动器 `Lwjgl3Launcher` 和 `DesktopPlatform`（Swing 选文件、OpenAL 变速）。
- `android/`：安卓平板启动器 `AndroidLauncher` 和 `AndroidPlatform`（复制 APK 里的谱面、系统文件选择器、MediaPlayer 变速）。平板排版由 `Gfx.tablet()` 打开，各界面按 `Gfx.TABLET` 换位置。

- 代码规范和游戏一样：每行不超过 120 个字；类说明先写一两句中文，再写英文；方法和行内注释用英文。`lwjgl3/` 里的 `StartupHelper` 是 libGDX 自带的文件，不改。
